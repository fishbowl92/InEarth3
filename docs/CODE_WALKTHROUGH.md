# InEarth3 핵심 코드 흐름

## 1. 버프 상태와 수치 분리

중심 파일은 [`MapManager.cs`](../MapManager.cs)입니다.

### 상태 저장 구조

- `BuffState`: 플레이어·골렘·몬스터의 버프 존재 여부를 정수 비트로 저장
- `buffListNew`: 버프 종류, 대상, 수치, UI 참조와 연결된 스킬 데이터를 저장

비트 플래그(Bit Flag, 정수의 각 비트를 참·거짓 상태로 사용하는 방식)는 버프가 존재하는지를 표시하고, 목록은 버프마다 달라지는 실제 정보를 보관합니다.

### 비트 연산

- `setBuffStateGab`: OR 연산으로 버프 비트를 켭니다.
- `getBuffStateGab`: AND 연산과 비트 이동으로 버프 존재 여부를 확인합니다.
- `removeBuffStateGab`: 반전 마스크와 AND 연산으로 버프 비트를 끕니다.

### 버프 획득 처리

`getBuffNewVersion`은 다음 순서로 동작합니다.

1. 대상과 버프 값이 유효한지 확인합니다.
2. 비트 플래그로 동일한 버프의 존재 여부를 확인합니다.
3. 기존 버프가 있으면 목록에서 해당 항목을 찾아 수치를 합산합니다.
4. 합산 결과가 0이면 버프와 UI를 제거합니다.
5. 새로운 버프라면 정보와 UI를 추가하고 해당 비트를 켭니다.
6. `buffImmediate`를 호출해 실제 능력치와 화면 표시를 갱신합니다.

이 구현의 의미는 모든 버프 데이터를 정수 하나에 저장한 것이 아니라, 존재 여부와 실제 데이터를 서로 다른 구조로 나눈 데 있습니다. 버프 수가 많지 않은 프로젝트이므로 정량적인 메모리 절감이나 성능 향상을 주장하지 않습니다.

## 2. 스킬 데이터

[`SkillBlock.cs`](../scriptable/SkillBlock.cs)는 다음 정보를 Unity 자산으로 구성합니다.

- 스킬 이름과 등급
- 대상과 비용·피해·반복 횟수
- 실행할 `UnityEvent`
- 효과 위치와 시각 효과
- 아이콘과 사운드
- 사용자에게 표시할 설명

전투 관리자는 선택한 `SkillBlock`의 데이터를 읽어 카드 비용, 효과와 화면 정보를 연결합니다.
