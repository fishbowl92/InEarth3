# InEarth3 회고와 개선 방향

## 2026-09-07 실제 수정

버프 활성화·조회와 해제의 비트 위치가 달랐고, 제거 함수에 대상 번호를 상태값으로 전달하거나 제거 전에 수치를 반환하는 오류가 있었습니다. 이를 두 함수에서 수정하고 실제 소스 기반 검사 514개 통과를 확인했습니다. 원본 코드와 후속 수정은 [수정 기록](./BUFF_STATE_FIX.md)에 구분했습니다.

아래 항목은 아직 적용하지 않은 개선 방향입니다. 전체 Unity 프로젝트 실행 검증은 수행하지 못했습니다.

## 유지할 설계 판단

- 버프 존재 여부와 실제 수치·UI 정보를 분리한 점
- 중복 버프를 새 항목으로 계속 추가하지 않고 기존 수치에 합산한 점
- 스킬마다 다른 정보를 `ScriptableObject` 자산으로 구성한 점
- 플레이어·골렘·몬스터의 버프 대상을 구분한 점

## 현재 다시 구현한다면 개선할 부분

### 비트 플래그 형식 명시

현재는 일반 `int`와 열거형 순서를 이용합니다. 현재라면 `[Flags]` 특성을 적용한 열거형을 사용해 각 비트의 의미를 코드에 명시합니다. `int`는 표현할 수 있는 비트 수가 제한되므로 버프 종류가 범위를 넘을 가능성도 검사합니다.

### 상태 조회와 목록 검색 통합

현재는 비트로 존재 여부를 확인한 뒤 목록을 다시 순회합니다. 현재라면 버프 종류를 키로 사용하는 `Dictionary`를 검토하여 존재 확인과 실제 데이터 접근을 한 구조에서 처리할 수 있는지 비교합니다. 버프 수와 접근 빈도를 측정한 뒤 구조를 결정합니다.

### 전투 규칙과 화면 표시 분리

버프 적용, 능력치 변경, UI 생성과 애니메이션 실행이 한 클래스에 함께 들어 있습니다. 현재라면 다음과 같이 분리합니다.

- `BuffService`: 버프 추가·합산·제거 규칙
- `CharacterState`: 실제 능력치
- `BuffPresenter`: 버프 아이콘과 애니메이션
- `SkillDefinition`: 스킬 설정 데이터

### 저장 형식 개선

진행 상태를 구분 문자가 포함된 문자열로 조합해 `PlayerPrefs`에 저장합니다. 현재라면 버전 필드가 있는 직렬화 데이터 구조를 만들고, 누락되거나 오래된 데이터에 대한 변환 규칙과 검증 테스트를 추가합니다.
